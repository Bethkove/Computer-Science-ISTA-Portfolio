# Research Notes

## Méthode de lecture

Pour chaque article :

### Pass 1 — 10 minutes
Lire :
- titre ;
- abstract ;
- introduction ;
- figures ;
- conclusion.

Objectif : comprendre le problème général.

### Pass 2 — 30 à 60 minutes
Identifier :
- problème précis ;
- idée principale ;
- méthode ;
- protocole expérimental ;
- résultat principal ;
- limites.

### Pass 3 — équations
Revenir sur les équations réellement nécessaires pour comprendre la méthode.

### Pass 4 — synthèse
Écrire :
- Research question ;
- Main idea ;
- Method ;
- Main result ;
- Limitation ;
- One possible next experiment.
